# RSVP-Reader
Rapid Serial Visual Presentation reading in Unity

![Unity](https://img.shields.io/badge/engine-Unity-blue)
![Language](https://img.shields.io/badge/language-C%23-239120)
![Status](https://img.shields.io/badge/status-In_Progress-yellow)

---

## 🚀 Features
- Rapid Serial Visual Presentation (RSVP) display of text  
- Words-per-minute (WPM) speed control and display  
- Looping option
- Loads text from a `TextAsset` (plain `.txt`) for easy testing

---

## 🧩 How to Use
1. Clone the repo.  
2. Open the project in Unity (recommended Unity 6000.0.58f2+).  
3. Assign a `TextAsset` to the RSVP player component in the inspector.  
4. Press **Play** in the Editor and use the controls above to interact.
